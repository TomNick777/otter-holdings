# 设计与收束

## 数据与展示

`simulation/scenario.ts` 是唯一演示输入：六个虚构账户、十三项虚构资产、期初数量与明确日期的数量变更。行情由独立的确定性函数生成；它不读取外部信息，不用当前市值反推交易。

`domain/replay.ts` 校验输入、准备月/年回放并采样过渡。期初未知保持未知，期初缺失拒绝回放。地块目录包括已清仓资产，以保证再次进入时身份稳定。

`domain/valuation.ts` 用 Decimal.js 计算数量 × 单价。任何一项缺少数量或价格，完整合计保持 `null`；已知小计独立保留。账户现金单独展示，不混入资产袖套曲线。

`domain/returns.ts` 保留原工程的通用收益语义：XIRR 需要已知外部流与期末价值，Modified Dietz 拒绝零或负分母，严格 TWR 要求资金时点前后估值和连续性证据。公开测试用新构造的案例验证这些边界，没有私人 golden inputs。

`application/portfolio.ts` 输出账户持仓、市值历史和城市 DTO。图表与当前表格共享金额出口，城市高度只消费数量及每项资产固定比例。React 仅把金额格式化和绘制为图表。

## 场景

`web/city/ThreeCity.tsx` 保留手工设计的六套园区与公共空间。道路、绿化与建筑地块不随数量改变。楼层按数量逐层生长；园区筛选改变镜头焦点，选择持仓高亮对应建筑。

页面提供侧栏和账户按钮，三维画布不是唯一入口。小屏布局将侧栏放在场景下方；回放控制放在独立区域，不覆盖建筑。系统减少动画时，数量采用离散状态，车流不自动启动。

## 清理取舍

- 公开版仅有一条 Three.js 城市入口，删除了旧 SVG 场景及其 World/Campus/Architecture/PublicRealm 依赖。
- 原先很大的页面入口由小型路由容器、城市、资产和作品说明组成；样式仅覆盖这些页面。
- 未复制整个 source tree、fixtures、账单或历史审计文档；仅提取纯展示和通用公式，并逐处移除账户身份常量。
- 不保留 Electron、数据库、来源同步、网络行情和一次性导入/修复脚本，依赖锁文件重新生成。
- 公开 Git 历史从此快照开始，与本地原项目历史分离。

## 验证范围

自动测试覆盖十进制金额、未知与零、完整性、收益边界、期初变更、稳定地块、清仓再进入，以及历史曲线与持仓表的金额一致性。

交互验收覆盖桌面与移动页面、账户选择、资产页、月/年回放、暂停/倍速/进度、WebGL 回退和项目子路径资源。当前证据等级以 `PROJECT_STATE.md` 为准。
